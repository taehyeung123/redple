# 레드플 (RedPle)

레드랭크 구독자 전용 네이버 블로그 어시스턴트 크롬 확장 프로그램.

검색량 조회부터 AI 원고 생성, 에디터 자동 입력, 법적 위험 검사까지 — 네이버를 쓰는 흐름 그대로 붙는다.

---

## 기능

### 1. 네이버 검색 결과 분석 카드
`search.naver.com`에서 검색할 때마다 우측 상단에 자동으로 뜬다.

- 월간 검색량 (PC / 모바일 분리)
- 블로그 문서수, 경쟁률(문서수÷검색량), 포화도
- 황금 키워드 / 경쟁 낮음·보통·높음 자동 판정
- **12개월 검색 트렌드 스파크라인**
- **SERP 노출 순서 분석** — 이 키워드에서 블로그·인플루언서·카페 중 뭐가 먼저 뜨는지

### 2. 블로그 에디터 도구 패널
`blog.naver.com` 글쓰기 화면에 사이드 패널로 붙는다.

- **레드랭크 원고 자동 입력** — 제목·본문·이미지를 한 번에 (실패 시 클립보드 폴백)
- 실시간 카운터 — 글자수(공백 제외/포함), 이미지·동영상 개수
- SEO 분량 가이드 (1,500자 기준 실시간 안내)
- **금지어·과장광고 표현 실시간 검출** — 최상급/절대보장/의료과장/순위주장 등 8개 패턴
- **법적 위험 검사** — 의료·법률·식품·금융 4개 분야, 위반 문구별 근거 법령과 수정안 제시
- **형태소 분석** — 본문 키워드 빈도 상위 20개 시각화
- "작성 중인 글이 있습니다" 팝업 자동 닫기

### 3. AI 원고 생성 (사이드패널)
- **10개 글 유형** — 제품/방문/업체/여행 후기, 정보성글, 원본재작성, 유튜브·뉴스 기반, 쿠팡·스마트스토어 홍보
- 유형별로 필요한 입력 필드가 자동으로 바뀜 (원본 자료 필수 여부, 경험 필수 여부)
- 메인 키워드 검색량을 작성 화면에서 바로 조회
- 문체 3종, 분량 500~3,000자, 이모지 On/Off, 추가 요청
- 생성 결과를 **네이버 에디터로 바로 전송**

### 4. 팝업 / 컨텍스트 메뉴
- 플랜·코인 잔액 확인
- 어디서든 키워드 빠른 조회
- 웹페이지에서 텍스트 선택 → 우클릭 → "레드플: 검색량 조회"

---

## 설치 (개발자 모드)

1. `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 저장소 폴더 선택

## 연결

1. [레드랭크 프로필](https://www.redrank.kr/profile)에서 **API 키 발급**
2. 확장 아이콘 클릭 → API 키 붙여넣기 → 연결하기

> AI 원고 생성·법적 검사는 **레드랭크 Basic 이상 구독자 전용**입니다.
> 무료 플랜은 키워드 조회 기능만 이용할 수 있습니다.

## 구조

```
manifest.json              MV3 매니페스트
src/
  background.js            서비스 워커 — 모든 네트워크 호출 담당
  common/
    storage.js             chrome.storage 헬퍼
    api.js                 백그라운드 메시지 브릿지
    categories.js          글 유형 정의 (레드랭크와 동기화 필요)
  content/
    naver-search.js/css    검색 결과 오버레이
    blog-editor.js/css     에디터 도구 패널
  popup/                   툴바 팝업
  sidepanel/               AI 원고 생성 워크스페이스
  options/                 설정 페이지
assets/                    아이콘 (16/32/48/128)
```

### 설계 원칙

- **네트워크는 백그라운드에서만.** 콘텐트 스크립트는 `chrome.runtime.sendMessage`로 요청하고, 실제 fetch는 서비스 워커가 한다 (CORS·권한 일원화).
- **네이버 세션은 절대 서버로 보내지 않는다.** 원고는 클립보드 기반 구조화 JSON(`__redrank_draft__`)으로만 전달된다.
- **자동 입력은 항상 폴백을 둔다.** 스마트에디터 DOM이 바뀌어 자동 입력이 실패해도, 본문을 클립보드에 복사해 사용자가 직접 붙여넣을 수 있게 한다.
- **어뷰징성 기능은 만들지 않는다.** 자동 댓글·공감·서로이웃 자동화는 계정 저품질 위험이 있어 로드맵에서 의도적으로 제외했다.

## 알려진 제약

- **이미지 자동 첨부는 실제 에디터에서 검증이 필요하다.** 숨겨진 file input에 File 객체를 주입하는 방식으로 구현했으나, 스마트에디터 ONE이 이를 받아주는지는 로그인된 실제 글쓰기 화면에서 확인해야 한다. 실패해도 제목·본문은 정상 입력되며 안내 메시지가 뜬다.
- **에디터 셀렉터는 다단계 폴백으로 구성했다.** 네이버가 DOM을 바꾸면 `src/content/blog-editor.js`의 `TITLE_SELECTORS` / `BODY_SELECTORS` 배열에 새 셀렉터를 추가하면 된다.
- **태그는 자동 입력하지 않는다.** 태그 입력창은 별도 컴포넌트라, 패널에서 복사 버튼으로 제공한다.
- 네이버 공식 [블로그 글쓰기 API](https://openapi.naver.com/blog/writePost.json)를 쓰면 DOM 조작 없이 발행까지 가능하지만, **사업자 등록 후 권한 심사**가 필요해 현재는 클립보드 방식으로 동작한다.

## 레드랭크 연동 API

| 용도 | 엔드포인트 | 인증 |
|---|---|---|
| 플랜·코인 조회 | `POST /api/extension/verify` | `X-RR-API-Key` |
| 키워드 검색량 | `GET /api/keyword/analyze` | 없음 (IP 제한) |
| AI 원고 생성 | `POST /api/ai/generate` | 로그인 쿠키 + 코인 |
| 법적 위험 검사 | `POST /api/ai/legal-check` | 로그인 쿠키 + 코인 |
| 형태소 분석 | `POST /api/nlp/analyze` | 로그인 쿠키 |
